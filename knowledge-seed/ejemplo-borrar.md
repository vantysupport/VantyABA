# Ejemplo de conocimiento (puedes borrar este archivo)

Este es un archivo de ejemplo para probar la carga de conocimiento por código.

Reforzamiento diferencial de conductas alternativas (DRA): estrategia ABA que
consiste en reforzar una conducta alternativa apropiada que cumple la misma
función que la conducta problema, mientras se deja de reforzar (extinción) la
conducta problema. Es especialmente útil cuando la conducta problema tiene una
función comunicativa clara (pedir atención, escapar de una demanda, acceder a un
objeto). Requiere identificar primero la función mediante un análisis funcional.

Cuando termines de probar que la carga funciona, borra este archivo y pon aquí
tus propios documentos de conocimiento clínico.
